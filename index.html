Compilar

Escolha o .zip do mod lá em cima. O app envia o zip ao seu repositório de build no GitHub, que compila e devolve o APK. Token: GitHub → Settings → Developer settings → Fine-grained tokens, só para o repositório de build, com Contents e Actions em Read and write. Fica salvo apenas neste aparelho.

O repositório é público: o zip é apagado da release assim que o build começa.
